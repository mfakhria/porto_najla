# Najla Putri Afifah — Portfolio

A cinematic, bright feminine pastel portfolio built with React 19, TypeScript, Vite 8, Tailwind CSS v4, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/` and can be deployed directly to Vercel.

Portfolio content is centralized in `src/data/portfolio.ts`, while the application starts from `src/main.tsx`.
