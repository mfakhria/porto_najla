# Portfolio — Najla Putri Afifah

Personal portfolio website built with **Laravel** and Blade.

## Stack

- PHP / Laravel
- Blade templates
- Static assets (CSS, images)

## Local setup

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Open `http://127.0.0.1:8000`.
